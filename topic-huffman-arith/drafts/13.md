# 怎麼選？Huffman vs 算術編碼
layout: table
| 面向 | Huffman 編碼 | 算術編碼 |
|---|---|---|
| 編碼單位 | 一個符號一個碼字 | 整則訊息一個小數 [card:huffman-vs-arithmetic#C5] |
| 速度 | 較快 | 較慢（需維護區間與精度） [card:huffman-vs-arithmetic#C7] |
| 專利 | 歷史上沒有專利問題 | 曾有許多專利，現多已過期 [card:huffman-vs-arithmetic#C8] |
| 常見應用 | DEFLATE（gzip）、JPEG、MP3 | 搭配機率模型的強力壓縮器 [card:huffman-vs-arithmetic#C9] |
- 算術編碼更貼近真實機率，但 Huffman 比較快、沒有專利包袱，所以仍然到處都是。[card:huffman-coding#C20]
