# 怎麼選？Huffman vs 算術編碼
layout: table
| 面向 | Huffman 編碼 | 算術編碼 |
|---|---|---|
| 編碼單位 | 一個符號一個碼字 | 整則訊息一個小數 [card:huffman-vs-arithmetic#C5] |
| 速度 | 較快 | （來源未比較原因） [card:huffman-vs-arithmetic#C7] |
| 專利 | 歷史上沒有專利問題 | 曾有許多專利，多已過期 [card:huffman-vs-arithmetic#C8] |
| 應用 | 前綴碼用於 DEFLATE、JPEG、MP3 | 搭配機率模型的強力壓縮器 [card:huffman-vs-arithmetic#C9] |
- Huffman 為何仍常見？除了較快，專利顧慮曾讓 bzip2 放棄算術編碼，JPEG 實作多用 Huffman。[card:huffman-coding#C20][card:arithmetic-coding#C12]
